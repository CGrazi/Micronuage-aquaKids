# Escola de Idiomas

Site criado no Micronuage.

## Como rodar

```bash
npm install
npm run dev
```

- `npm run build` — gera a versão de produção
- `npm test` — roda os testes

Feito com: React, Vite, TypeScript, Tailwind CSS, React Router.

## Pedido original

O que foi pedido quando o site foi criado na Micronuage:

> Eu tenho uma escola de natação para crianças , meu objetivo é criar um site informativo com preços e imagens que chamem a atenção de quem visualizar o site
